# Setup Finds UK

Independent, research-led UK buying guides for gaming gear, PS5 accessories and practical desk upgrades. Readers should be able to find a category, understand suitability and trade-offs, compare existing shortlists, and follow the exact retailer link when ready.

The site is static HTML, shared CSS and JavaScript. Node/esbuild bundles the existing Motion mini effects; Python generates the local search index. GitHub Pages deploys from main using the existing workflow.

Preserve published URLs, SEO metadata, useful content, analytics consent, affiliate tracking and disclosures. Do not invent prices, specifications, ratings, reviews or hands-on testing claims. Named-product images must remain matched to the actual catalogue item. Lifestyle and generic category imagery are illustrations, not evidence of a specific product or tested setup.

The user-approved white/blue/oak screenshot is the visual authority for this iteration. Do not restore the former dark green palette or let generic skill preferences override the target.
